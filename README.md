# 🖱️ Clicker Game

[![Unity](https://img.shields.io/badge/Engine-Unity-black?logo=unity&style=flat-square)](https://unity.com/)
[![Language](https://img.shields.io/badge/Language-C%23-blue?style=flat-square)](https://docs.microsoft.com/en-us/dotnet/csharp/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**Clicker Game** is a simple incremental idle game inspired by *Idle Slayer* and *Clicker Heroes*. Players click to earn coins, purchase upgrades, and automate their income.

## 🎯 Project Goals
- Strengthen C# and Unity development skills.
- Practice creating scalable game systems (upgrades, progression).
- Explore idle game mechanics like auto-clicking and passive generation.

## 🕹️ Features
- **Active Clicking**: Click to collect coins manually.
- **Upgrades**: Spend coins to upgrade click value and passive income.
- **Auto-Clickers**: Unlock automated coin generation.
- **Dynamic Scaling**: Upgrade costs increase as you progress.
- **Prototype Save System**: Saves basic player progress.

## 🚀 How to Play
1. Clone this repository.
2. Open the project in Unity 2021.3 (or later).
3. Press `Play` to start.
4. Click to earn coins and buy upgrades!
